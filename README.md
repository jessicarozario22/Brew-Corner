## 📖 Project Overview

**Brew Corner** is a coffee shop website designed with a warm and elegant visual style. The page presents the café brand, story, popular coffee selections, key services, opening hours, and contact information in a clean one-page layout.

The project was built using **HTML5 and CSS3**, with a focus on visual hierarchy, clean structure, responsive layout, and a user-friendly browsing experience.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Main Features

* Responsive navigation bar
* Hero section with coffee-bean background
* Call-to-action button
* About / Our Story section
* Popular Picks / Menu section
* Feature highlights:

  * Fresh Beans
  * Fast Delivery
  * Made With Love
* Opening hours table
* Promotional banner
* Footer with brand information, quick links, and contact details

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/jessicarozario22/Brew-Corner.git
```

2. Open the project folder:

```bash
cd Brew-Corner
```

3. Open `index.html` in your browser.

No package installation or build tool is required for this HTML/CSS project.
